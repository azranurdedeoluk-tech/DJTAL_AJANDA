# 📱 DİJİTAL AJANDA (Digital Agenda)

C# Windows Forms kullanılarak geliştirilmiş, kişisel planlama ve takip süreçlerini kolaylaştıran masaüstü uygulaması.

## 🚀 Özellikler
* **Günlük & Not Yönetimi:** Günlük tutma ve önemli notları kaydetme.
* **Sağlık & Alışkanlık Takibi:** Su tüketimi, uyku ve günlük alışkanlık takibi.
* **Kitaplık Modülü:** Okunan kitapların kaydı ve takibi.
* **Kullanıcı Dostu Arayüz:** Kolay ve pratik kullanım.

## 🛠️ Kullanılan Teknolojiler
* **Dil:** C#
* **Framework:** .NET Framework
* **Arayüz:** Windows Forms (WinForms)
* **Geliştirme Ortamı:** Visual Studio 2022
